Leonida Platinum Log — an offline GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies. Every trophy carries its official name, description and grade, a guide in our own words with each step citing its source, a count tracker where the trophy has a count, and a 7-stage roadmap to the platinum. One trophy is flagged possibly missable (Positive Mental Attitude) and nine hidden trophies with no confirmed method are labelled unconfirmed instead of given invented steps. Progress saves in the browser (localStorage), exports to a file and imports back; filters cover story, missable, collectibles, activities, crime, world, strangers and PSN-hidden, and a spoiler shield hides story trophies until they are earned. The app is static files only and works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
